Method notes

  • The dataset is bilingual. A document's language is detected by comparing how many Indonesian and English stopwords it contains.
  • Indonesian text is stemmed with Sastrawi (Nazief–Adriani); English text with the Porter stemmer.
  • Queries are usually short, so each query token is stemmed both ways and the form that exists in the index is kept.
  • Implementation: engine/preprocessing.py.
