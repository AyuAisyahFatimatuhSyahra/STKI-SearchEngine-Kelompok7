How the weights are computed

Implemented by hand in engine/tfidf.py (indexing and weights) and engine/vsm.py (cosine and ranking), without a library vectorizer.

1 Term frequency

tf(t, d) = occurrences of t in d

Counted on the stemmed tokens of each document.

2 Inverse document frequency

idf(t) = log10 (Ndf(t))

N = {{ stats.n_docs|thousands }} documents. Rare terms weigh more; the maximum is {{ max_idf|num(3) }} when df = 1.

3 TF-IDF weight

w(t, d) = tf(t, d) × idf(t)

The query vector q is weighted the same way.

4 Cosine similarity (VSM)

cos(q, d) = Σw(t,q) · w(t,d) √Σw(t,q)² · √Σw(t,d)²

Documents are ranked by cos(q, d), highest first; a score of 0 is not shown.

At search time, cosine is computed only for documents listed in the postings of the query terms, not for all {{ stats.n_docs|thousands }} documents. That is what the inverted index is for.
